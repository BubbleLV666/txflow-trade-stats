Trading stats for any address on TxFlow

Paste an address — the site queries the public TxFlow API directly and shows equity, PnL, volume, fees, positions with liquidation prices, maker/taker split, per-market breakdown, funding, deposits and withdrawals. No keys or sign-in needed; the address is sent nowhere except the TxFlow API.

TxFlow points are not shown per address: the API returns them only to the wallet owner after sign-in. There is also no per-address leaderboard rank or equity history in the public API.

Unofficial project, not affiliated with TxFlow. Data comes from the public API api.txflow.com; it may lag or contain exchange errors.
